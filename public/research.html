🔍 시장조사

📈 데이터 시각화 시장 현황

시장 규모

  • 글로벌 데이터 시각화 시장: $8.85B (2023)
  • 연평균 성장률(CAGR): 10.2%
  • 2030년 예상 규모: $19.20B
  • 한국 시장 규모: 약 500억원 (추정)

주요 트렌드

  • 실시간 데이터 분석 수요 증가
  • 셀프서비스 BI 도구 선호
  • 클라우드 기반 솔루션 확산
  • AI/ML 통합 시각화

🎯 타겟 사용자

1차 타겟: 중소기업 데이터 분석가

  • 규모: 직원 10-500명 기업
  • 페인포인트: 복잡한 BI 도구, 높은 비용
  • 니즈: 간단하고 직관적인 시각화

2차 타겟: 개인 창업자/프리랜서

  • 규모: 1-10명 소규모 팀
  • 페인포인트: 예산 부족, 기술적 진입장벽
  • 니즈: 저렴하고 사용하기 쉬운 도구

🏢 경쟁사 분석

Tableau

  • 강점: 강력한 기능, 대기업 선호
  • 약점: 높은 가격($70/월), 복잡한 UI
  • 시장점유율: 약 35%

Power BI

  • 강점: MS 생태계 연동, 합리적 가격
  • 약점: 제한적 커스터마이징
  • 시장점유율: 약 25%

Google Data Studio

  • 강점: 무료, Google 서비스 연동
  • 약점: 제한적 기능, 성능 이슈
  • 시장점유율: 약 15%

💡 문제 정의 & 가설

🔴 핵심 문제

"중소기업과 개인 사용자들이 데이터를 시각화하고 싶지만, 기존 도구들은 너무 복잡하거나 비싸다"

구체적 문제점:

  • Tableau, Power BI는 월 $20-70로 부담스러운 가격
  • 복잡한 인터페이스로 학습 비용이 높음
  • 간단한 차트 하나 만들기도 시간이 오래 걸림
  • 실시간 데이터 연동이 어려움

🟢 솔루션 가설

"직관적이고 저렴한 웹 기반 데이터 시각화 도구를 제공하면, 중소기업 사용자들이 쉽게 데이터를 분석하고 의사결정할 수 있을 것이다"

핵심 가치 제안:

  • 간단함: 3클릭 이내로 차트 생성
  • 저렴함: 월 $5-15 가격대
  • 실시간: 즉시 데이터 업데이트
  • 협업: 팀 단위 공유 및 편집

📋 MVP PRD (Product Requirements Document)

🎯 MVP 목표

3개월 내에 기본적인 데이터 시각화와 대시보드 기능을 제공하여 초기 사용자 100명 확보

✅ MVP 핵심 기능

1. 데이터 입력

  • CSV 파일 업로드
  • Google Sheets 연동
  • 수동 데이터 입력

2. 기본 차트

  • 선형 차트
  • 막대 차트
  • 원형 차트
  • 기본 커스터마이징

3. 간단한 대시보드

  • 차트 배치 및 크기 조정
  • 대시보드 저장/불러오기
  • 공유 링크 생성

📊 성공 지표

사용자 지표

가입자 100명
월 활성 사용자 50명
차트 생성 500개

제품 지표

차트 생성 시간 < 2분
페이지 로딩 < 3초
사용자 만족도 > 4.0/5.0

🚫 MVP에서 제외할 기능

  • 고급 통계 분석 (회귀분석, 예측 등)
  • 복잡한 데이터 변환
  • 사용자 권한 관리
  • API 연동 (DB, 외부 서비스)
  • 모바일 앱

📅 MVP 개발 일정

1개월차: 기초

  • 프로젝트 설정
  • 기본 UI/UX 디자인
  • 데이터 입력 기능

2개월차: 핵심

  • 차트 생성 엔진
  • 기본 차트 3종
  • 대시보드 레이아웃

3개월차: 완성

  • 공유 기능
  • 성능 최적화
  • 베타 테스트
