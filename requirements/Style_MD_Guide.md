
# Claude 기반 코딩 스타일: 프로젝트 문서 작성 가이드

이 문서는 Anthropic Claude를 사용하는 개발 환경에서 자주 활용되는 `.md` 파일들과 각 문서별 목적, 템플릿, Claude용 프롬프트 예시를 정리한 가이드입니다.

## 📄 주요 Markdown 파일 개요

| 파일명              | 목적 요약 |
|---------------------|-----------|
| README.md           | 프로젝트 개요, 설치법, 사용법 안내 |
| CONTRIBUTING.md     | 기여 방법과 코드 스타일 가이드 |
| DESIGN.md           | 시스템 설계 목표 및 모듈별 상세 설계 |
| ARCHITECTURE.md     | 전체 아키텍처 구성과 컴포넌트 설명 |
| DECISIONS.md        | 주요 설계 및 기술 선택의 결정 이력 |
| PROMPT_GUIDELINES.md| Claude 등 LLM을 위한 프롬프트 작성 가이드 |
| CLAUDE.md           | Claude 모델에게 지속적으로 적용할 프로젝트 규칙 요약 |

## ✅ 각 문서별 템플릿 및 Claude 프롬프트

### 1. README.md

**목적:** 프로젝트 소개 및 사용법 안내  
**Claude 프롬프트 예시:**  
> 우리 프로젝트는 **데이터 시각화 앱**이야. 설치법, 기능, 사용 예시 등을 포함한 README.md를 마크다운 형식으로 작성해줘.  

**템플릿 주요 항목:**
- 소개
- 기능 목록
- 설치 및 실행 방법
- 사용 예시
- 기여 안내
- 라이선스

---

### 2. CONTRIBUTING.md

**목적:** 외부 기여자 안내 및 코드 규칙  
**Claude 프롬프트 예시:**  
> 오픈소스 기여자를 위한 CONTRIBUTING.md를 작성해줘. 이슈 신고법, PR 절차, 코드 스타일을 포함시켜줘.

**템플릿 주요 항목:**
- 기여 환영 인사
- 이슈 및 PR 작성법
- 코드 스타일 및 테스트
- 커뮤니케이션 채널
- 행동 강령 링크

---

### 3. DESIGN.md

**목적:** 시스템 설계 문서  
**Claude 프롬프트 예시:**  
> 우리 프로젝트의 DESIGN.md를 만들어줘. 시스템 개요, 요구사항, 모듈별 설계, 데이터 모델을 포함해줘.

**템플릿 주요 항목:**
- 개요
- 요구사항
- 시스템 구성도
- 상세 모듈 설계
- 데이터 설계
- 보안 및 성능
- 대안 비교

---

### 4. ARCHITECTURE.md

**목적:** 전체 코드 구조 및 시스템 흐름 정리  
**Claude 프롬프트 예시:**  
> 프론트엔드, 백엔드, DB, 외부 API로 구성된 시스템의 ARCHITECTURE.md를 작성해줘.

**템플릿 주요 항목:**
- 시스템 구성도
- 주요 컴포넌트 설명
- 배포 및 인프라
- 의사결정 요약

---

### 5. DECISIONS.md

**목적:** 주요 아키텍처/기술 결정 기록  
**Claude 프롬프트 예시:**  
> 최근 3가지 결정 사항을 DECISIONS.md 형식으로 정리해줘. 날짜, 결정, 이유, 대안, 영향 포함.

**템플릿 주요 항목:**
- 날짜
- 결정 요약
- 배경 및 근거
- 고려된 대안
- 영향

---

### 6. PROMPT_GUIDELINES.md

**목적:** Claude 등 LLM 사용을 위한 프롬프트 작성 규칙  
**Claude 프롬프트 예시:**  
> Claude에게 요청할 때 지켜야 할 프롬프트 작성 규칙을 PROMPT_GUIDELINES.md 형식으로 정리해줘.

**템플릿 주요 항목:**
- 명확한 지시 작성법
- 컨텍스트 제공 방식
- 예시 포함 방법
- 출력 형식 지정법
- 어조 설정 및 주의사항

---

### 7. CLAUDE.md

**목적:** Claude에게 항상 주입할 프로젝트 정보 요약  
**Claude 프롬프트 예시:**  
> Claude가 항상 기억해야 할 규칙들을 CLAUDE.md 파일로 정리해줘. 언어, 스타일, 포맷 규칙 등 포함.

**템플릿 주요 항목:**
- 사용 언어
- 출력 포맷 및 구조
- 어조와 스타일
- 주석 및 코드 작성 방식
- 금지어 또는 제한사항
